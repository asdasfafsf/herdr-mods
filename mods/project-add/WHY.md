# project-add 를 만든 이유

사이드바 헤더의 폴더 버튼이 여는 Add project 창(Orca 의 "프로젝트 추가"). 하는 일은 `lib/project.js` 이고, 에이전트의 `hm clone`·`hm project` 도 같은 함수를 부른다.

## Herdr 기본
사이드바 `+` 는 빈 space 하나(지금 터미널의 폴더에서). 다른 폴더를 고르거나, 레포를 clone 하거나, 새 프로젝트를 만드는 화면은 없다.

## 모자랐던 것
새 레포를 사이드바에 넣으려면 터미널에서 직접 clone·mkdir 하고 그 폴더로 space 를 만들어야 했다.

## 더한 것
- Browse folder(Enter): 시스템 폴더 선택 창. 레포나 일반 폴더는 space 로 열리고(레포면 사이드바에서 레포로 묶임), 레포가 여럿 든 폴더(`~/Desktop/workspace` 같은)는 안의 레포 목록을 보여줘 골라서 각각 space 로 연다(처음엔 아무것도 안 고름, Pick all, 이미 열린 건 흐리게). 에이전트는 `hm add 폴더`(안 열린 레포 전부).
- Clone from URL: Git URL 과 부모 폴더(기본은 마지막에 쓴 곳, 없으면 레포들이 가장 많이 있는 폴더). 새 space 의 터미널에서 clone 한다: exec 는 30초에 끊기고, 로그인을 물으면 터미널에서 답해야 하므로. 끝나면 셸이 그 폴더에 남아 레포로 보이고, 실패하면 이유를 말하고 셸로 남는다. 시작 직후 같은 clone 을 또 하면 막는다.
- New project: 이름과 부모 폴더. 빈 폴더에 `git init` 과 빈 첫 커밋(바로 워크트리를 만들 수 있게), space 로 연다.
- Host: 연결된 원격 머신이 있으면 고를 수 있다(원격은 폴더 선택 창 대신 경로 입력).

## 걷어낼 조건
Herdr 에 프로젝트 추가 화면(폴더 고르기·clone·새로 만들기)이 생기면 뺀다.

## 옮길 때 가져갈 것
`project.parent`(`shared.json`): 머신별 마지막 부모 폴더. 버려도 된다.
