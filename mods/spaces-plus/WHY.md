# spaces-plus 를 만든 이유

사이드바. Herdr 에 딸린 `spaces` 의 복제본(원본은 `upstream/spaces/`).

## Herdr 기본
space 마다 색 아바타, 열린 워크트리 space 는 그 체크아웃 밑에, 머신이 여럿이면 머신별로. space 이름 뒤에 브랜치·ahead/behind(평범하지 않을 때만). 에이전트 상태는 Agents 목록에만. 클릭·우클릭 메뉴·드래그 정렬. 사이드바 위 `+` 는 빈 space 하나. 단축키는 `ctrl-1..9`(space 선택)와 탭·에이전트 이동.

## 모자랐던 것
- space 로 열지 않은 워크트리는 안 보인다. primary 체크아웃이 열려 있지 않으면 워크트리가 레포 밑으로 들어가지 않는다.
- 레포를 묶음으로 접을 수 없고, 워크트리 밑의 터미널·에이전트가 안 보인다.
- 워크트리에 사람이 붙이는 이름·링크·PR·메모가 안 보인다.
- 안 쓰는 워크트리를 닫으면 그 안의 에이전트 세션을 잃는다(Sleep 없음).
- 에이전트가 git 으로 워크트리를 지우면 그 space 가 남는다(폴더가 없어 git 을 못 돌리는 걸 "원격이 끊김" 처럼 보고 예전 정보를 유지).
- `+` 로 다른 폴더를 열거나 터미널만 띄우기 불편하다.
- 드래그하는 동안 행이 따라오지 않고 놓을 자리가 행 안쪽 얇은 선이라 모호하다.
- 사이드바 순서대로 워크트리를 오가는 단축키가 없다.

## 더한 것
- Orca 식 묶음: 레포 헤더 → primary → 워크트리 → 그 터미널. 안 연 워크트리는 흐린 행(누르면 열림). primary 가 닫혀 있어도 묶음 유지(primary 는 흐린 행).
- 레포·워크트리·터미널 접기(들어가면 펴지고 떠나면 접힘), 배지(브랜치·PR·링크·열린 포트·메모), 정렬(활동·최근·이름·만든 순).
- PR 상태: 레포마다 `gh pr list --author @me` 를 5분마다 한 번 읽어 브랜치와 맞추고, 배지에 열림·머지됨·닫힘·초안과 CI 결과(✓ ✗ …)를 보인다. gh 가 없거나 모르는 레포면 `wt.meta` 의 PR 번호만.
- 레포 헤더의 정리 버튼: 다 끝난 워크트리 정리 창(`worktree-plus`).
- Sleep: 그 안의 Claude·Codex 세션을 `wt.sleep` 에 먼저 기억하고 닫으며, 열면 처음 띄운 옵션 그대로 이어 열기. 지원 에이전트가 있는데 ID를 식별하지 못하면 닫지 않고 이유를 알린다. `hm sleep`도 결과를 기다린다. Codex 공유 서버는 터미널을 닫아도 작업을 계속할 수 있어 Sleep이 서버 작업 중단을 보장하지는 않는다.
- 밖에서 지운 워크트리: 폴더가 사라지면 space 를 닫고 알림(에이전트가 일하는 중이면 "removed" 표시 후 끝나면).
- 헤더 버튼 셋(한 번에 누르기): Add project(`project-add` 창), New terminal, New worktree. 드래그 미리보기와 묶음 경계 선.
- 단축키 `⌘⇧↓/↑`, `⌘⌥]/[`(다음·이전), `⌘⌥T`(새 터미널·에이전트).
- 에이전트용 명령(`spaces-plus.go@`, `meta@`, `create@`, `remove@`, `sleep@`, `sessions@`, `sort@`; `hm` 이 부름).
- Herdr 가 원본 `spaces` 를 바꾸면 알려주고 3-way 병합(`scripts/sync-upstream.sh`).

## 걷어낼 조건
- Herdr 사이드바가 안 연 워크트리까지 레포 밑에 보이고, 레포를 접고, 워크트리 밑 터미널을 보이면: 묶음 부분은 Herdr 것으로, 우리는 배지·메뉴·Sleep 만.
- Herdr 가 밖에서 지운 워크트리를 정리하면 `vanished` 를 뺀다.
- 드래그·헤더 버튼이 Herdr 에 같은 수준으로 생기면 뺀다.

- 이름·링크 같은 워크트리 정보는 `worktree-plus` 의 `wt.meta`.
