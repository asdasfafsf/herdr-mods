# agents-plus 를 만든 이유

Agents 목록. Herdr 에 딸린 `agents` 의 복제본(원본은 `upstream/agents/`).

## Herdr 기본
Herdr 가 띄운 에이전트를 상태별·우선순위로 보여준다. 본 done 은 떠날 때까지 Done 에 남는다.

## 모자랐던 것
- Orca·iTerm·VS Code 등 Herdr 밖에서 도는 Claude·Codex 가 안 보인다(Herdr 로 옮기는 중에도 다 한곳에서 보고 싶음).
- 보고 있는 탭의 에이전트가 done 이 되면 아래로 밀려 찾기 어렵다.
- 목록이 많을 때 다시 그리기가 중단되면, 지금 답하거나 승인해야 할 에이전트를 목록에서 확인할 수 없다. 작업이 많아져도 목록을 읽을 수 있어야 하고 이름·상태 변경도 바로 반영돼야 한다.
- 오류 스택만으로는 어느 구간에 시간이 들었는지 몰라 추측으로 최적화하게 된다. 평소 구간 시간과 당시 목록 규모를 비교할 수 있어야 한다.

## 더한 것
- 공유 Codex 서버는 PID 하나에 여러 세션을 가질 수 있다. 열린 writer별로 나누고 Herdr 복원 기록에 있는 ID는 제외한다. 원래 터미널 앱을 확정할 수 없는 것은 `Codex server`로 표시하며, 행 ID도 PID 대신 세션 ID를 쓴다.
- 바깥 에이전트(`outside.py`: Claude 는 `~/.claude/sessions`, Codex 는 `ps`·`lsof`)를 같은 상태 묶음에 앱 태그와 흐린 아이콘으로. 누르면 Herdr 에서 이어 열기(이미 Herdr 에 있으면 그리로, 원래 앱의 것은 그대로).
- 맨 위 Active 묶음: 지금 보는 탭의 에이전트.
- 소식이 있을 때만 두 번째 줄: 일하는 중이면 지금 하는 일(▸ Editing main.py, Running npm test; 도구 사이에는 이번 요청에서 마지막으로 한 말, 없으면 마지막 단계 · thinking…), 기다리는 중이면 허용을 기다리는 명령(?), 끝났으면 답의 첫 줄(✓). 쉬는 에이전트는 한 줄 그대로. 각자의 세션 기록(Claude `~/.claude/projects`, Codex rollout)의 끝만 읽고, 바뀐 것만 다시 읽는다(`activity.py`, 창이 앞에 있을 때 3초마다). Orca 는 같은 정보를 Claude 훅으로 받는데, 여기선 훅 없이 기록에서 읽는다.
- 레포 · 브랜치: 마우스를 올리면, 같은 이름의 행이 둘 이상이면 행에 바로(사이드바의 `wt.trees`).
- worktrees 번들이 없으면 스스로 이어 연다(그 폴더를 담은 space 의 새 탭, 없으면 새 space).
- 렌더 한 번에 pane·워크트리·외부 행 메타데이터를 한 번씩 읽어 함께 쓴다. 행마다 전체 데이터를 다시 복사·정렬하지 않는다. 다음 렌더에는 새로 읽어 변경된 이름·경로가 묻히지 않게 한다. 재현·전후 측정은 [성능 개선 기록](../../docs/render-performance.md).
- Seen 기간·읽음 상태·보기 옵션·레포 색도 렌더당 한 번 읽는다. 작업 재개 시 지난 읽음 표시를 먼저 제거하고, 클릭·비동기 갱신은 새 값을 읽으므로 방금 한 읽음 처리나 설정 변경을 이전 스냅샷으로 덮지 않는다.
- 하위 에이전트는 부모별 목록을 한 번 만들고 긴급도·행 생성에 함께 쓴다. 깊이마다 전체 터미널을 다시 찾지 않으며, 자식 종료·부모 변경은 다음 렌더에 반영한다.
- 구간별 렌더 시간을 메모리에 집계하고 60초마다 렌더 밖에서 저장한다(`hm logs --render`). 느린 완료와 종료 기록이 없는 실행을 구분하며, 후속 실행까지의 대기 시간을 렌더 시간으로 오인하지 않는다. 기록 때문에 화면을 추가로 갱신하지 않는다. 보존·유실 조건은 [UI 진단](../../docs/ui-diagnostics.md).

- Seen: 끝난 에이전트를 보고(done → idle) 대꾸하지 않으면 2시간 동안 Working 과 Idle 사이 "Seen"(보라 테두리, 다른 상태와 겹치지 않는 색)으로 둔다. 봐 놓고 놓친 걸 Idle 더미에 묻히지 않게. 판정은 `lib/ui.js` 의 `shownStatus` 하나, 본 시각은 agents-plus 가 `ag.info[address].seen` 으로 공유. 사이드바·⌘P 도 같은 표시.

## 걷어낼 조건
에이전트를 전부 Herdr 로 옮기면 바깥 목록은 필요 없다. Herdr 가 "지금 보는 것을 위로" 를 하면 Active 를 뺀다. Herdr 가 에이전트의 지금 단계와 마지막 답을 보여주면 두 번째 줄을 뺀다.
