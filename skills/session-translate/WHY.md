# 세션 이동·번역이 해결하려는 불편

이 문서는 기준 코드와 스킬에 나타난 **기능의 목적**을 정리한 것이다. 특정 과거 요청이나 장애가 있었다는 이력은 추정하지 않는다.

## 기존 도구가 하는 것

Claude Code와 Codex는 자기 형식의 세션을 자기 CLI에서 resume/fork한다. 에이전트마다 기록 위치와 메시지 형식이 다르고, Claude는 프로젝트 경로와 기록 위치가 연결돼 있다.

## 불편한 점

- 같은 에이전트의 대화를 다른 worktree에서 이어가려면 세션에 남은 cwd/프로젝트 위치를 맞춰야 한다.
- Claude에서 Codex 등으로 바꾸면 기존 요청·작업 결과를 다시 설명하거나 복사해야 한다. 원본 기록은 서로의 resume 입력이 아니다.
- 같은 대화를 여러 에이전트로 보내려면 대상마다 변환하는 연결이 필요하다.

## 더한 것

- `hm resume --into`: 정지한 같은 에이전트 세션의 기록 경로/cwd를 옮긴 뒤 그 checkout에서 연다. 실행 중이면 거부한다.
- `agent-session/1`: 원본을 공통 메시지로 export하고 대상별 adapter로 새 세션을 만든다. `hm translate`, `hm resume --as`, 독립 `translate.py`가 사용한다.
- 원본을 변경하지 않는 변환, 대상별 새 ID, 여러 대상으로 한 번에 변환.

## 기대를 제한해야 하는 부분

기준 버전은 도구 기록을 텍스트로 옮기고, 긴 결과를 자르며, 이미지 원본·모델 reasoning·서브에이전트를 보존하지 않는다. 세션 파일 생성 성공만으로 새 CLI에서 resume 성공이나 의미가 완전히 보존됐다고 볼 수 없다. [동작 명세](../../docs/porting/behavior.md)와 AC-S03/AC-S04를 적용한다.

## 걷어낼 조건

새 앱/에이전트가 폴더 변경과 교차 에이전트 대화 전달을 제공하고 동일한 보존·손실·원본 유지 기준을 충족하면 그 기능에 연결한다. 같은 컴퓨터에서 **앱만 바꿀 때**는 원본 에이전트 CLI의 resume만으로 충분할 수 있으므로 세션 변환을 강요하지 않는다.

## 옮길 때 가져갈 것

이미 만든 `~/.herdr/agent-sessions/*.jsonl`, 원본 세션 식별자와 필요한 에이전트 원본. 새 앱의 space/tab ID는 가져가지 않는다. 전체 이전 절차는 [이식 안내](../../docs/porting/README.md).

Codex에서 native `resume --cd`로 폴더를 바꾼 뒤 번역할 때는 과거 rollout 헤더가 아니라 현재 SQLite cwd를 사용한다. 예전 폴더로 잘못 이어받지 않기 위한 규칙이며, DB가 없는 구버전은 기록의 cwd로 대체한다.
